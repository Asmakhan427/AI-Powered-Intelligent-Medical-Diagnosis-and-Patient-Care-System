# No explicit pydantic pin -- fastapi and chromadb each pull in their own
# compatible version; pinning exactly here forced pip's resolver to
# backtrack through both packages' full version histories looking for one
# combination that satisfies an unnecessarily specific constraint.

# chromadb pins tokenizers<=0.20.3 transitively; left unconstrained,
# sentence-transformers' unpinned `transformers` dependency makes pip search
# backward from the newest transformers release looking for one whose own
# tokenizers requirement happens to satisfy that cap -- observed to not
# converge in a reasonable time. Pinning both explicitly to versions known
# to satisfy chromadb's constraint skips the search entirely.
tokenizers<=0.20.3
transformers<4.47
